# 安全探索与持续页面学习

在页面缓存后台 `/cache` 选择“配置新任务”，明确设备、已安装 App 和有限测试时长，并确认所选模型的截图与消费提示。步数、Token 默认选择“不限制”，也可分别设置上限。新功能与当前页预热、普通 Run Task 独立，首版只支持 Android，不自动选设备或跨 App。

## 配置与控制

- 先在设备上打开目标 App，避开敏感页面。最大有效时长为 1–1440 分钟，初始为空且必填。步数和 Token 默认“不限制”，只用时长预算；取消对应勾选后，需填写 1–20000 步或 1–10000000 Token。API 使用 `null`（或省略对应字段）表示不限制，0 仍是无效输入，时长不允许不限制。
- 探索读取 `config/artemis.jsonc` 的 `nodes.operator`，学习读取 `nodes.utils.object_detector`，缺省继承 `default`。界面显示实际展开后的主路由；不自动使用 fallback。无需添加无关 Provider 的 Key。模型/目的地改变需停止后新建并重新授权。
- 暂停：不再派发新工作，等待当前有超时限制的模型请求结算，丢弃失效结果，释放设备。处理中不等于已经暂停。继续重新观察同一设备/App，保留时长、步数和 Token 累计值。
- 停止：收敛并清理后为终态；保留报告与缓存，不允许继续此任务。已经下发的动作不能撤销。
- 关闭或刷新浏览器不改变执行状态。后台退出后任务显示中断，必须显式继续；后台重启不会自动跑长任务。

只开放有观察与语义证据的导航点击、普通容器滑动及返回。删除、发送、分享、购买、支付、业务提交、录音、账号修改、自由文本、任意 shell 等不进入动作入口。未知语义拒绝执行；登录、权限、支付或不可观察窗口、离开目标 App 等暂停等待手工处理。模型识别可能出错，安全模式不承诺绝对正确或完整覆盖。

## 预算和学习口径

运行中的观察、学习、模型等待计入有效时长；排队、暂停和恢复校验除外。实际下发的失败动作也计步数。所有模型调用在请求前预留额度、响应后按供应商完整用量幂等结算；缓存/推理 Token 不重复相加。预留是调度估计，当前请求仍可能超额；不展示准确费用金额。

设置 Token 上限时，剩余额度不足以合理准入新请求即结束，预算未必恰好归零；选择不限制时，不会因为 Token 或步数累计变大而结束，仍显示累计数据。时长、安全检查、页面容量及可继续分支等规则继续生效。用量缺失、取消后无法确认最终用量时保留未结算项目并暂停；不能记成零或重置预算。停止后的迟到可信用量可以补记，但不能复活任务或写入旧学习结果。崩溃时预留的短时间片保守核销，避免恢复后返还未知执行时间。

每个稳定页面检查 inventory，完整可复用页面跳过整页付费学习，部分/失效页面有限补学，每页最多两次尝试。XML 直接定位不跳过学习检查。名称只作展示，识别与定位仍由设备、包名、Activity、页面指纹/结构和局部证据决定。名称缺失显示 Activity/包名与指纹，不展示孤立 unknown page。

“本次学习成功”“已有缓存跳过”和“复访查询命中”是不同指标。学习写入不伪造命中；原有“预热后复访命中率”只记录学习后的真实目标查询。报告列出页面当前结果、尝试次数和有界状态历史；结束不等于 App 全覆盖。

## 本地数据与资源

任务库位于本机应用数据目录的 `cache-exploration.sqlite3`，缓存继续沿用现有视觉缓存路径，二者不上传、不提交。可通过任务中的“查看本地报告”读取脱敏状态和逐页结果。默认不增加全程录屏、页面原图或完整模型回复的留存；推理临时图片调用后清理，客户端/供应商自身留存不由本库保证。

每任务最多 2000 个页面身份，历史最多 1000 个任务，账本总体容量有上限。步数设为不限制时没有隐藏的 20000 步限制，20000 只是选择有限步数时允许配置的最大值。达到存储容量后拒绝新增或结束并保留现有报告，不静默删缓存或任务。新 worker 使用现有按设备互斥，普通任务和预热不会并发占用同一设备。

## 验证说明

可执行逻辑/接口测试：

```sh
.venv/bin/python -m pytest tests/unit/admin_console/test_cache_exploration_*.py -q
```

前端测试和构建需使用项目要求的 Node.js 版本：

```sh
cd apps/showcase_ui
npm test -- --watch=false --browsers=ChromeHeadless --reporters=dots
npm run build
```

真机验收使用 `tests/fixtures/cache_exploration_app/` 的无权限、无网络原生测试 App。它有 Home、About、Help 页面和无业务副作用的危险操作计数器；应始终显示 `Forbidden actions: 0`。这样可验证实际推理/页面学习/导航，而不外发个人业务页面。

已有 JDK 和 Android SDK（platform 35、build-tools 36.0.0）时可构建夹具；脚本不下载或安装软件，只在临时输出目录生成测试 APK 和本地测试签名：

```sh
python3 tests/fixtures/cache_exploration_app/build.py --sdk "$ANDROID_SDK_ROOT" --output /tmp/artemis-cache-lab
adb -s SERIAL install -r /tmp/artemis-cache-lab/cache-lab.apk
adb -s SERIAL shell am start -n org.artemis.cachelab/.MainActivity
```

将 `SERIAL` 替换为明确选择的验证设备；只在准备测试时安装。后台选择该 App，配置时长/可选限额并确认模型使用后验证。新签名与旧夹具冲突时需先移除旧测试夹具；不要卸载真实业务 App。夹具自定义 Back 会回到 Home，若落点与探索栈预期不同应暂停，不能为跑满时间而放开该保护。

本次真实验证已覆盖后台启动、实际模型用量、页面学习、正常暂停结算、同任务继续、预算结束、缓存实际查询命中；完整结果与边界见 [验收记录](./superpowers/reports/2026-10-27-safe-monkey-learning-acceptance-report.md)。受控测试不代替真机证据；特定业务 App 的覆盖率、复杂滑动、动态登录态和长期体验仍应在明确目标和预算下自行验证。
