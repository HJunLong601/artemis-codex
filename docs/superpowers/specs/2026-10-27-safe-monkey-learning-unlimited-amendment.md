# 安全探索预算修订：可选不限步数与 Token

日期：2026-10-27。用户明确要求“最大操作步数 和 token 新增一个不限制的选项 只保留monkey测试的时间”。该最新指令覆盖先前产品/交互/技术规格中“三项预算必须有限”的约束；用户已授权实现负责人处理方案及设计，不再逐门禁确认。

当前阶段：实施与验证。默认开启步数和 Token 的“不限制”，有效时长仍为必填有限正整数。两项分别可取消勾选，启用原有限上限。配置变化会取消消费确认；开始后配置冻结，同一任务暂停/继续不重置累计值。

接口用 `max_steps: null`、`max_tokens: null` 或省略对应字段表示不限制，不使用极大整数或 0 伪装无限；旧整数配置保持原行为。后台持续统计实际步数与已知 Token，只有启用的额度才参与耗尽判断。有限时长、设备互斥、安全策略、用量未知处理、停止终态及容量保护保持有效。

选择不限制的任务可能在时长内持续消耗模型额度，界面与文档明确说明。历史有限预算任务不自动改为不限；验收涵盖两种配置、恢复累计和时长始终生效。
