## 三、推荐技术路线

采用**后台管理的专用安全探索 worker + 有界结构化模型调用 + 本地持久化任务账本**。复用 Android 驱动、设备互斥、现有模型配置/认证、页面指纹和缓存校验；不把普通 Flash/Pro 的自然语言目标当作唯一执行器。

每个已激活设备最多一个 worker，暂停释放设备并退出执行段；显式继续时加载同一任务账本，新建执行段并重新观察。后台监督 worker 存活，但后台重启只将遗留运行标为中断，绝不自动恢复长跑。

单轮闭环：读取控制意图及预算 → 验证设备与 App → 获取稳定画面 → 登记页面并检查/补齐学习 → 生成安全导航候选 → 策略过滤、去重及选取 → 再观察与派发前校验 → 记账并下发一个动作 → 等待稳定并记录转换。学习与探索都纳入同一闭环，没有不受预算管理的后台辅助调用。

首版每个任务仅一个在途模型请求、一个在途手机动作；禁止动作 burst。这样既可长时间运行，也能逐项落实安全、预算和暂停契约。不是按任务长度改用普通 Pro，也不新增独立规划、摘要或多代理推理链。

| 类型 | 选择与职责 | 限制 |

| 运行与接口 | 现有 Python、asyncio、FastAPI、Pydantic | 不引入 Redis、Celery、远程服务或新包管理器 |

| 页面学习 | 当前 `utils.object_detector` 主路由及现有 inventory 规则 | 最多 20 个可信常用控件；所有请求接任务调用入口 |
| 模型工厂与适配 | 复用 Endpoint/原始模型构建，新增任务专用调用约束 | 不使用全局暂停 wrapper；SDK 隐藏重试必须关闭或可逐次计量 |
| 本地存储 | SQLite 任务账本，现有视觉缓存库继续使用 | 账本与缓存各自迁移；不要求重建、上传或清空数据库 |
| UI | 现有 Angular 缓存页与轮询 | 不以浏览器连接维持执行；关闭页面不会取消任务 |

启动与继续仅核验实际探索/学习两条路由：视觉输入、结构化输出、认证状态、用量完整性、请求超时及取消能力。不要求无关的 API Key、OCR、Pro 节点或视频工具。如果两个角色实际路由相同，去重检查。读取诊断不发推理；若需能力探针，必须在启动授权后作为本任务调用纳入预算，不将有费用推理藏在刷新或预检中。

供应商支持采用能力判断，不根据品牌猜测：本机源码有 Codex、Google、OpenAI、Anthropic 等路由，但不据此宣称均通过新功能验证。Codex 沿用当前进程的认证路径，不复用本对话的模型会话；Anthropic 路由不等于 Claude Code 桌面/CLI 登录集成。新增此功能不扩展 Claude Code 认证。

任务启动时固定模型路由和非敏感配置摘要。配置被外部修改后继续应暂停并提示配置变化，不能悄悄使用新目的地；需要改变路由时新建任务、重新授权。仅凭凭证存在不认定实际推理成功。

Codex 任务专用适配需保留 thread/turn 标识与原始用量事件，支持针对该请求发出中断并等待有界完成通知；不修改已安装依赖文件、不全局 monkeypatch、不终止共享客户端。当前依赖不能直接满足该契约，推荐在项目适配层显式实现并测试所需生命周期。无法确认远端取消时仅保证本地结果失效及不再派发，不承诺账单立即停止。

模型只返回受限 JSON，不获得 shell、MCP、自由代码或手机工具权限。沿用 Codex inference-only 的嵌套 MCP 禁用机制，并验证原生工具限制；任何工具启动事件不得被解释为允许执行的探索动作。若当前客户端无法满足隔离契约，应阻止该能力激活并说明原因，不能仅靠提示词宣称禁用。

## 五、安全探索与页面学习

### 5.1 动作约束

模型候选只允许 `navigate(element_ref)`、`scroll(container_ref, direction)`、`back` 和 `no_safe_action`。输出须引用本次观察中的元素/容器；不接受模型自造 shell、输入文本、任意坐标、按键名或成组动作。多余字段、未知动作和缺失证据拒绝。

派发前由程序检查：任务仍运行、执行段未失效、设备锁归属、目标 package/Activity、观察新鲜度、页面结构及元素边界。点击必须具有导航语义证据、可交互角色与目标上下文；删除、发送、分享、购买、录音、账号修改等禁用语义优先否决，并检查父级/邻近表单或弹窗语境。文字黑名单只是补充，不能单独放行。

优先使用 XML ID/层级和当前元素定位；XML 不足时可使用当前截图中可信识别的导航区域，但必须同样通过策略，并在执行前重新确认位置/语义。缓存坐标只能帮助定位，不能充当安全许可。无法确认语义、归属或命中范围就跳过，不降级成随机点击。

滑动仅限确认的普通滚动容器内部，避开滑块、拖拽排序、下拉刷新、侧滑删除区域和屏幕系统手势边缘；无法确认容器则不滑动。Back 仅在本执行段有可信 App 内导航栈且非根页面时允许；返回目标无法确定则暂停，不尝试返回到桌面后再自动拉起。

每个动作后重新检查前台窗口，敏感/权限/登录/支付窗口、外部 App 或不可观察状态立即暂停。即使 package 相同也检查窗口/画面，不以包名相同放过敏感弹窗。执行层没有任意 shell 入口；包清单和必要设备观察由固定只读命令完成，不接受模型命令字符串。

导航语义仍可能被模型或 UI 元数据误判，安全模式不是绝对无误承诺。若通用安全证据不足，允许该页停止拓展并说明原因；不能为提高覆盖率降低规则。对特定 App 的后续规则扩展应有独立证据与回归。

### 5.2 覆盖、去重与补学

- 使用已有设备/包名/Activity/页面指纹与结构守卫；名称只作展示。同标题不同结构不合并，标题变化不直接增页。结构相似只生成候选，不能跳过像素/布局一致性验证。
- 稳定观察至少两次，间隔约 300ms，最多等待 5 秒；不要求截图字节完全相等，比较已有结构/布局及忽略区域证据。仍不稳定记跳过，不对动画反复请求模型。
- 每个稳定页先检查 inventory；可信且完整则跳过整页模型调用，失效/部分页有限补学。XML 直接找到导航目标也不绕过此检查。
- 将单页预热拆出“已持有设备锁和任务调用器下的观察/学习”复用入口，外层原接口继续独立取锁。不能在探索 worker 内再次调用完整 `warm_current_page()` 造成锁重入。
- 学习租约、页面 generation、执行段、目标 package/Activity 与当前画面共同校验。模型返回后先结算 Token，再校验是否允许写缓存；停止后即便结果可信也丢弃。
- 空 inventory 是“无可信常用控件”，不伪报新增元素；任务内记住结果避免反复付费。缓存淘汰不触发同一任务无限重学；报告区分“本次曾学成”和“当前仍可复用”。
- 探索采用有界页面/导航边集合，优先未尝试的安全分支；同页同动作默认只尝试一次，确认为无状态变化的失败最多再尝试一次。滚动无新结构连续两次即关闭该方向分支。到达安全分支尽头结束并报告未学项，不宣称 App 全覆盖。

## 六、累计预算与请求生命周期

### 6.1 持久化记账

任务 ID 跨暂停、继续、刷新和进程恢复保持不变；每次继续生成新执行段。按唯一调用 ID / 操作 ID 登记，不以模型回复数、循环轮数或临时会话累计替代任务预算。

| 额度 | 请求前与结算规则 |
| --- | --- |
| 有效时长 | 运行段内以单调时钟计算并定期持久化，包含模型等待和学习；排队、暂停、恢复校验除外。每次调度都检查，定时器只作为及时唤醒 |
| 操作步数 | 派发闸门内原子预留并登记，再下发一个动作；已下发失败仍计数。崩溃造成已预留但结果未知时保守保留，不退回额度，不自动重放 |
| Token | 每个模型尝试先持久化请求及预留额度，再发出；成功/失败/取消都结算已知实际值，唯一调用 ID 防重。定位、学习、重试、能力探针与未来摘要均不得绕过 |

Token 账本使用供应商已报告且完整的总量，保留输入/输出/缓存/推理等原始语义。缓存 Token 已包含在输入时不再相加；供应商总量已包含推理时也不重复加。归一化适配必须检查字段存在性与一致性，不能将缺失字段补零后标为完整；记录是单请求数还是累计快照，累计事件按可验证差额计算，不能逐事件累加快照。

普通任务的 `SessionTokenMeter` 可以继续接收观测数据，但新任务的强约束账本不吞掉持久化错误。账本写入失败即关闭派发闸门，暂停或中断并释放设备，不能继续执行再补统计。

### 6.2 请求预留与在途限制

任务内只允许一个在途模型调用。`已结算 + 在途预留` 达到预算不再派发。请求预留参考有界输入/图像规模、供应商支持的输出上限及推理额度；支持可靠计数的适配器使用该能力，否则明确是保守调度估计，不能声称服务商硬计费上限。

单次结构化输出建议上限 4096 Token；供应商支持时实际设置。Codex 当前未透传 `max_tokens`，不得假设此限制有效，应使用严格输入规模、串行请求、剩余额度检查及用量事件观测；请求无法以当前剩余额度合理准入时以“Token 预算不足以发起下一请求”结束。预留估计与最终实际量都保留，不用估计覆盖实际数据。

实际用量超过预算时停止后续调用并展示超额值，不裁剪到上限；只有一个在途请求限制了同时暴露面，但无法保证单请求超额幅度。UI 已确认必须披露这一点。

响应、取消或超时后缺少完整用量时，保留该请求为未结算，任务暂停“用量不可确认”，禁止新调用和自动重试。只有补回可验证用量后才允许继续；无法补回时保持不可恢复的中断/暂停，只能停止保留未知项，不提供清零或人工填零入口。结束后的迟到可信用量可幂等补记报告，不改变终态、不执行动作、不写学习结果。

### 6.3 超时、重试与收敛

推荐请求总超时 60 秒，并取不超过本次剩余有效时长；观察及设备动作也取有限超时。时长到期或用户暂停/停止时先关闭派发门、撤销执行段，再有界取消/等待在途调用。开始处理不意味着远端已经结束。

每页学习最多两次尝试；可确定未发出的临时网络错误最多重试一次，且重新检查预算。已可能发出但计量未知的请求不能自动重试。模型返回格式错误先记实际消耗，再决定在剩余两次配额内重试。认证/权限错误不重试，不进入全局暂停文件循环。

SDK 内部重试设为零，或必须能提供每次尝试 ID 和用量；两者均做不到则该适配器不满足长任务严格计量条件。禁止把应用层“两次尝试”误报为实际只请求两次。

## 七、暂停、停止、恢复与本地存储

推荐独立本地 SQLite 任务账本放在现有运行数据目录内，不写入仓库或配置文件。持久化任务目标、冻结预算、路由摘要、状态版本、执行段、请求账、操作账、页面/导航边、控制意图及脱敏事件；不存凭证、完整模型回复、原始截图或 XML。具体表名、模块归属由架构阶段确认。

采用事务、唯一约束和状态版本比较实现幂等。控制请求先记录意图返回处理中，唯一 worker 在同一控制闸门内处理状态变化、模型派发、动作派发和缓存写入；处理队列不能绕过该门。事件通知仅加速界面，持久化状态是事实来源。

暂停/停止意图接收后立刻请求关闭派发门；已开始派发的单个动作属于在途，不能撤销。只有 worker 确认派发关闭、执行段失效、在途回调不能产生副作用且设备资源释放后，才能显示已暂停/已停止。处理中不承诺手机立即静止。

缓存写入与执行段检查必须位于同一受保护临界区，避免检查通过后被停止再写入。API 不直接写学习结果；过期 worker 或回调无权更新新段。监督进程只可按匹配 PID、创建时间及任务归属终止失联 worker，不能杀共享模型进程或无关设备任务。

任务账本与缓存库不强行伪装成跨库事务：先记录本地意图，缓存操作确认成功后再记页面结果。崩溃于两步之间时，恢复核验 inventory/租约及 generation 后修正报告，不能重复派发手机动作或重做已完成学习。现有缓存函数部分异常会被吞掉，因此复用入口必须返回可核验的写入结果。

继续先读取同一任务并抢占式比较状态版本，非阻塞获取同设备锁，重新校验 App/画面/模型配置和剩余额度。设备忙则保留暂停，不排一个可能稍后自动启动的恢复任务；终态停止的状态比较永久拒绝恢复。

后台退出后所有未确认运行段标已中断。崩溃前最后已提交账本作为下界：未结算请求不清零；有效时长以预写入的短时间片预留保守核销，剩余时间不能因崩溃增加。正常结束回填实际单调时钟用时，无法判断的短片在报告标为保守核销。架构阶段必须给出该时间片和崩溃窗口的精确规则，不用跨进程单调时钟或系统时间倒退推导可用额度。

## 八、接口契约与资源限制

以下为技术层接口建议，最终 DTO/错误枚举在架构阶段冻结；不能直接复用不具任务 ID 的全局继续接口。

| 接口建议 | 行为 |
| --- | --- |
| `GET /api/system/visual-cache/exploration/capabilities` | 只读返回支持平台、三预算范围、实际路由摘要和已知能力，不推理 |
| `GET .../exploration/apps?device_serial=...` | 对明确授权设备执行有界只读清单查询；名称无法可靠获取时用包名，不下载资源或向模型询问 |
| `POST .../exploration/tasks` | 必填设备、包名、三个预算、授权及幂等键；创建后异步校验/执行，返回任务 ID 和状态版本 |
| `GET .../exploration/tasks`、`GET .../tasks/{id}` | 状态与进度读取，分页查本地历史；无启动副作用 |
| `POST .../tasks/{id}/pause`、`resume`、`stop` | 带控制幂等键和期望版本；返回处理中/现态；终态不复活 |
| `GET .../tasks/{id}/pages`、`report` | 分页学习结果与脱敏报告；不返回截图或个人页面文本 |

所有控制接口采用已有 loopback/same-origin 检查，新增明确 intent 头；不能挪用登录 intent。服务端检查目标、授权、预算、同设备互斥和任务状态，不依赖按钮禁用。幂等键相同且请求内容相同返回原任务，内容不同返回冲突；HTTP 超时不能促使重复创建。

客户端轮询建议运行/处理中每 2 秒、暂停/终态按需读取；请求失败显示最后确认状态，重连不发送继续。刷新统计与任务状态独立。错误按可恢复性返回稳定原因码和脱敏说明，不透传异常堆栈或原始模型响应。

推荐首版资源上限如下，均为技术评审建议而非现有实现：

| 项目 | 上限或策略 |
| --- | --- |
| 最大有效时长 | 1–1440 分钟，表单仍默认空值 |
| 最大操作步数 | 1–20000 步 |
| 最大 Token 用量 | 1–10000000 Token；小额度允许配置，但不足以调用时直接解释结束 |
| 在途模型 / 动作 | 每任务各最多 1 个；两者不并发推进页面 |
| 学习重试 | 每页最多 2 次尝试，每次均计量 |
| 页面 / 导航边 | 每任务最多 2000 个页面身份、20000 条边；达到容量后结束，原因与预算用尽区分 |
| 事件明细 | 每任务最多 50000 条，重复原因聚合；保留累计和最终摘要，不以截断伪报完整轨迹 |
| 本地报告容量 | 账本按逻辑有效载荷限制单任务 50MiB、总体 250MiB，数据库页/WAL另留空间余量；达到上限结束/拒绝新增并提示清理，不静默删任务或缓存 |
| 画面资源 | 内存中仅保留当前轮必要帧，调用后及时释放；不默认启用全程录屏、页面原图或完整轨迹引擎留存 |

清单查询有界超时，使用现有设备寻址逻辑构建固定参数，包名严格校验，不拼接用户命令。读清单不抢占正在运行的设备；设备忙时提示稍后读取或先暂停。

## 九、兼容、隐私与迁移

- 新能力以独立入口增量接入，不改变普通 `/api/run`、全局暂停文件、模型默认值或现有任务 profile。既有路径继续可用，但不是新任务控制入口。
- 单页预热提取可复用逻辑后仍保持原请求、同源/授权、超时和设备锁行为；已有缓存命中口径不变。新学习写入不伪造视觉查询，复访命中按真实查询计数。
- 新任务账本使用版本化幂等迁移；缓存若需增加确认字段只能增量迁移，失败时禁用新功能并解释，不删除旧库。旧版后台不读取新任务控制，不自动恢复新任务。
- 截图确需送给已展示的模型，不能承诺画面天然无敏感信息；启动提示要求先避开敏感页面，运行中发现敏感流程暂停。稳定控件标签入库前仍用既有校验，不保存联系人、文本输入值或业务列表内容。
- Codex 适配会经过临时图像文件；新任务调用要求可控临时目录、文件权限和 finally 清理，崩溃后仅清理归属明确的过期临时文件。供应商/客户端自身留存不由本库保证，说明不能只写“本地不存”等同于远端不留存。
- 路由摘要仅包含供应商、模型及非敏感目的地主机标识；移除 URL 凭证、敏感参数。日志只记录原因码和请求标识，不输出认证信息、截图 base64 或完整响应。
- 默认不启动现有全量录屏/轨迹保存；如后续需要此类证据留存，应额外设计开关、授权与容量，不能借本任务静默开启。
- 运行数据不提交 Git。本轮只新增文档，不安装依赖、修改配置、启动 worker、全局更新或提交代码。

## 十、备选方案与取舍

| 方案 | 优点 | 缺点 | 决定 |
| --- | --- | --- | --- |
| 普通 Flash/Pro 加安全目标提示词 | 接入量小，现有录制/报告较全 | 通用工具、全局暂停、辅助调用和 burst 难满足新契约；提示词不能承担程序安全边界 | 不采用为核心执行器 |
| 原始 `adb shell monkey` + 定期截图学习 | 随机操作吞吐高 | 无语义边界，可能发送/删除/跨 App，无法逐动作安全控制 | 不采用 |
| 浏览器发请求循环 + 单页预热 API | UI 实现简单 | 页面关闭中断，设备锁重入，累计预算和恢复不可靠 | 不采用 |
| 专用受控循环，复用驱动/配置/缓存 | 能逐请求/动作计量、限制能力、持久化恢复 | 需新增控制状态与适配契约，必须验证安全识别和供应商边界 | 推荐 |
| 外部调度系统或云端设备池 | 跨机任务管理能力强 | 超出本地范围，引入部署和隐私成本 | 首版不采用 |

## 十一、主要风险及缓解

| 风险 | 缓解与激活前要求 |
| --- | --- |
| 模型把业务动作误判为导航 | 受限输出、程序策略、上下文否决、每步重观察、未知拒绝；受控恶意/敏感场景与授权 App 真机验证 |
| 取消后远端继续消费 | 任务专用中断、单请求在途、明确未知结算；本地结果失效，未知用量禁止继续 |
| 隐藏重试/用量字段不全 | 适配器关闭重试或逐次观测，原始字段完整性校验；不合格路由显式拒绝，不能绕过计量 |
| 暂停与动作/缓存写入竞态 | 唯一 worker、控制闸门、执行段、持久化意图及终态约束；可注入交错验证 |
| 动态页重复学习或标题误合并 | 指纹/结构守卫、任务级尝试集合、稳定窗口及容量限制；名称只展示 |
| 后台重启或磁盘错误 | 不自动恢复，账本写失败关闭派发，未知操作不重放，独立迁移与可恢复性报告 |
| 页面学习记录与缓存容量不一致 | 报告分别记录本次学习与当前可复用，淘汰不回退任务累计，不无限重学 |
| 克制安全规则造成覆盖有限 | 明确跳过原因和剩余分支，不用危险动作换覆盖率；后续独立增加有证据的 App 规则 |

## 十二、验证策略、完成条件与后续边界

| 安全负例 | 删除/发送/分享/购买/录音/账号/表单、恶意截图指令、遮挡、系统弹窗、包名相同敏感窗口、外部 App 和无语义坐标均不能越权执行 |

| 授权真机端到端 | 从缓存页开始有限任务，实际推理、导航、新页学习、复访、暂停/释放/继续、停止终态；记录明确设备/App/预算、任务标识、脱敏状态证据 |
