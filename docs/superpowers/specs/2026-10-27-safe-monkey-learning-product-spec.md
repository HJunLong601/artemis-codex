## 一、已确认输入与评审范围

用户已确认：首版采用安全探索模式，限定一个 App，不做删除、发送、购买和账号修改；时长、步数和 Token 预算可配置，支持暂停、停止和继续；保留已有改动。

目标用户是在本机后台执行设备测试、希望通过较长时间探索积累本地视觉缓存的开发和测试人员。入口位于现有 `/cache` 页面，与“学习当前页面”并存。

本规格将上述方向细化为可评审规则。暂停与停止的区别、预算口径及异常处理是本次评审内容，不将用户前一条方向确认当作这些细节已经通过。

## 四、功能范围与非目标

### 范围

1. 从缓存页创建、查看和控制长时间探索学习任务。
2. 明确选择一台已授权的 Android 设备和一个已安装 App 的包名，不自动猜选目标。
3. 在安全边界内探索，优先发现未访问页面及未覆盖的导航分支，而不是持续点击同一位置。
4. 对实际观察到的稳定页面安排学习；不因控件能通过 XML 定位就跳过整页学习。
5. 使用当前配置的模型，不另建认证体系，不擅自切换模型供应商。
6. 任务与学习结果仅保存本地；页面刷新后可继续查看状态。

### 非目标

- 不执行原始无语义的随机点击，不把 `adb shell monkey` 当作安全模式的等价实现。
- 不保证访问整个 App 的所有页面、隐藏状态、不同账号数据或全部业务分支。
- 不要求每个页面的全部控件都进入缓存；沿用每次最多 20 个可信常用控件的边界。
- 不新增跨设备任务迁移、多 App 联合探索、iOS、云端调度、共享账号或自动登录。
- 不自动提交、推送、发布或全局安装；实际设备长跑需独立启动和截图授权。

## 五、输入与运行规则

### 启动配置

- 必填：目标设备、App 包名、最大有效运行时长、最大操作步数、最大 Token 用量。
- 三个预算均为有限正整数，不用空值或 `0` 表示无限。首版不预填可能造成无意消费的无限预算；具体上界由后续技术和交互阶段核定并前后端一致校验。
- 开始前展示模型来源、截图发送目的及费用风险，用户显式确认后才创建可执行任务。
- 设备、App 和预算校验失败时不启动任务；同一设备存在运行任务时不并发占用，不悄悄换设备。
- 关闭网页不等于停止后台任务；页面必须提示这一点，重新打开可找回运行状态。

### 安全操作边界

- 仅允许已识别为安全导航的点击、普通页面滑动和返回。返回若会离开目标 App，则不执行或转为暂停等待处理。
- 不开放自由文本输入、长按、拖拽、任意 ADB 命令、安装卸载或系统设置修改。
- 禁止删除、发送、分享、购买、支付、提交业务表单、录音、创建业务数据、账号修改和退出登录；不是仅靠按钮文字黑名单判断。
- 身份、语义、作用或目标 App 归属无法确认时，不执行动作；记录跳过原因。不能仅依赖模型提示词承担安全控制。
- 不自动点击系统授权、登录、认证或支付弹窗。离开目标 App、出现敏感流程、异常窗口或失去可观察状态时暂停，并说明原因。
- 不通过更换坐标、重试或直接驱动命令绕过安全拦截。识别可能出错的风险须在真实设备验收中单独检验，不能承诺模型判断绝对无误。

### 持续学习与覆盖口径

- “所有涉及页面”指任务实际观察到、位于目标 App 内的稳定页面，均有学习记录或明确的跳过原因；不表示整个 App 的覆盖率达到 100%。
- 以设备、应用、Activity 和页面指纹/结构证据识别页面；名称只用于展示。页面变体可以是不同记录，不能仅按标题合并。
- 每个稳定页面先检查学习状态：新页面或需补齐页面安排学习，已完成且可复用页面不重复请求整页学习；动态内容不能导致无限重复学习。
- XML 可直接定位时，仍应执行页面学习状态检查；页面一直不稳定时，标记未能学习而不是伪报完成。
- 当前页学习与普通任务已有缓存能力保持兼容。学习请求的截图必须来自当前真实观察；识别期间页面变化、任务停止或执行段已失效时，旧结果不得写入或执行。
- 学习失败采用有限重试；暂时无法学习的页面记为失败待重试或跳过，不能无限消耗模型。具体重试次数在技术阶段定义为有界配置。
- 仅缓存可信常用控件，不缓存个人字段值、联系人、录音内容或列表业务数据。默认不为了此功能额外保存全程录屏或所有页面原图；若复用现有轨迹留存，需要在后续阶段明确开关、提示和容量限制。

### 预算口径

| 预算 | 规则 |
| --- | --- |
| 有效时长 | 任务运行中计时，模型等待与学习也包含；暂停、排队和恢复校验期间不消耗探索时长 |
| 操作步数 | 每个实际下发的点击、滑动、返回计一步；失败动作也计数，组合动作逐项计数；观察和学习不伪装成手机操作步数 |
| Token | 所有归属该任务的探索、定位、页面学习、重试及后台摘要请求都计入；按供应商已返回的用量合并，输入中的缓存 Token 不重复相加 |

- 任一预算达到限制即停止发起新动作或模型请求，任务以“预算用尽”结束，不显示“已遍历全部页面”。
- 暂停、继续、刷新或进程恢复都不能清零本任务累计用量；并发辅助调用也不能绕过预算。
- 请求前需要预算检查与在途请求控制；供应商的用量通常在响应后才完整可见。预算是本地调度控制，不是服务商费用绝对硬上限，界面需展示这个限制。
- 模型请求的实际用量缺失或无法可靠计量时，不能记成零并无限继续，应暂停并提示“用量不可确认”。
- 首版仅在未启动时编辑预算；暂停后的预算调整交互可在后续规格中选择，但不得在未确认新增消费时静默放宽限制。

## 六、状态与控制

| 状态 | 允许动作与预期结果 |
| --- | --- |
| 未启动 | 编辑配置和授权；不会触发设备或模型 |
| 启动校验中 | 验证设备、应用、认证和预算；可请求停止，失败时给出脱敏原因 |
| 运行中 | 探索与学习，实时更新进度；可暂停或停止 |
| 暂停处理中 | 不下发新动作、不启动新模型请求；取消或收敛在途调用，尚未收敛时不能提前标记已暂停 |
| 已暂停 | 持久化进度并释放设备；不自动探索、不在后台继续学习；可继续或停止 |
| 恢复校验中 | 重新检查设备、目标 App、当前画面和剩余预算；不得沿用旧截图坐标 |
| 停止处理中 | 停止新工作、撤销在途结果、清理任务资源；资源尚未释放时不显示已停止 |
| 已停止 | 本任务终态，缓存及报告保留，不自动恢复；如需再跑，由用户显式创建新任务 |
| 已结束 | 达到预算或无可继续的安全分支，显示明确原因、剩余未学页面与消费，不代表完整覆盖 App |
| 已中断 | 后台退出、设备断连或不可恢复错误；保存可用进度，不自动重启长任务，可由用户显式继续或停止 |

“继续”只针对已暂停或可恢复的已中断任务；重新获取同一设备并保留本任务累计预算。用户已经停止的任务不会被自动复活。该语义属于本评审版待确认规则。

暂停时允许其他任务使用设备，因此继续必须重新观察；设备忙碌或 App/账号环境变化时保持暂停，不抢占、不自动重新登录。

## 七、页面输出与报告

- 显示目标 App、任务状态、开始时间、累计有效时长、操作步数与各预算剩余量。
- 显示 Token 已知用量及计量是否完整，按探索/学习/其他辅助调用区分；不能把 Token 直接当成准确金额。
- 页面统计至少包含：发现、学习成功、已有缓存跳过、不稳定跳过、安全拦截、学习失败、待重试。
- 报告中逐页解释未学原因、有限重试与最后结果；“探索结束”和“学习全部成功”分别表述。
- 复访指标仍按现有已学习页面的再次视觉目标查询计数，不能把预热请求或学习写入伪造为缓存命中。
- 复用现有容器自适应布局；增加指标数量不得再次引入按卡片序号跨列的规则。

## 八、异常与验收标准

| 场景 | 必须验证的结果 |
| --- | --- |
| 缺少设备、App、预算或截图授权 | 不启动任何任务；后端同样拒绝绕过前端的请求 |
| 目标 App 内安全导航 | 允许的导航可执行，访问稳定新页后形成学习记录 |
| XML 直接定位 | 不漏掉该页的学习检查，且不伪造视觉缓存查询/命中 |
| 重访同页、名称不同、动态页面 | 去重与补学有据可查，不按标题误合并，不无限新增或重复学习 |
| 删除、发送、分享、购买、录音、账号修改等入口 | 在实际动作下发前拦截；缺少语义证据时跳过，不能靠提示词独自保证 |
| 离开目标 App、登录/权限/支付弹窗 | 不扩大操作范围，暂停并说明原因 |
| 三类预算分别耗尽 | 每项均能单独阻止新请求/动作，辅助调用也纳入；不伪报整体覆盖完成 |
| 暂停、继续、停止的重复点击和竞态 | 幂等；无双执行器、无预算重置、无迟到坐标动作或缓存写入 |
| 暂停后页面被手工改变 | 重新观察与安全校验，不执行旧坐标 |
| 刷新页面、后台退出及恢复 | 状态可查询，后台退出不会被显示为仍在正常运行，恢复需人工触发 |
| 学习失败、超时、取消、认证失效及用量缺失 | 有限重试或暂停/结束；保留脱敏原因并释放相应资源，不影响无关任务 |
| 真实设备验收 | 在明确设备、App、预算及截图发送授权后进行；受控模型/合成页面测试不替代真机结果 |
| 兼容性回归 | 既有缓存和单页预热可用，宽屏/窄屏布局正常，无关改动与本地测试保持原样 |
