## 三、页面结构与启动表单

缓存页顺序：标题 → 当前页预热 → **安全 Monkey 与页面学习**面板 → 原有统计和缓存明细。新任务状态读取独立于统计刷新；统计失败不隐藏已知任务及控制入口，刷新统计不启动任务。

面板默认展示已有任务摘要；无任务时说明“在一个 App 内安全探索，学习实际访问的稳定页面”，按钮“配置探索任务”。同一设备有未结束任务时优先展示该任务，不重复创建。其他设备任务通过任务列表选择，不自动切换用户当前目标。

| 字段 | 初始及输入行为 | 校验与反馈 |
| --- | --- | --- |
| 目标设备 | 空选择；读取已授权 Android 设备，展示名称、简短标识及空闲/忙碌 | 必须明确选择；忙碌、未授权及离线不可开始，不自动选择其他设备 |
| 目标 App | 选择设备后读取已安装 App，按名称或包名搜索，始终展示完整包名 | 必须明确选择且确认安装；清单失败允许重试，不猜测前台 App |
| 最大有效时长（分钟） | 空值，正整数 | 必填；拒绝零、负数、小数、非数值及超出服务端能力范围的值 |
| 最大操作步数（步） | 空值，正整数 | 同上；说明点击、滑动、返回实际下发即计数，失败也计数 |
| 最大 Token 用量（Token） | 空值，正整数 | 同上；探索、定位、学习和辅助调用合计，不等同于费用金额 |
| 当前模型 | 只读展示当前执行与学习所用的供应商、模型和截图目的地 | 来源不可确认时不允许开始；本面板不新增模型切换或登录体系 |
| 截图与消费确认 | 默认未勾选，不从上次任务继承 | 文案明确持续发送该 App 截图至上述模型并消耗额度；设备、App、预算或模型改变后取消勾选 |

预算字段不预填消费值，不提供无限选项；最大值和范围说明由后续技术方案统一定义，前后端采用同一限制，越界显示字段旁错误，不截断成较小值。加载设备/App 清单只读取信息，不启动探索或学习。

表单常驻提示：

- “仅进行安全导航、滑动和返回；不执行删除、发送、购买、账号修改等业务操作。无法确认的动作将跳过或暂停。”
- “关闭网页不会停止后台任务；需要结束时请点击停止。”
- “Token 可能在请求结束后才返回。额度控制用于限制后续调度，在途请求可能使最终用量超过设置值。”
- “仅学习实际访问到的稳定页面，不代表遍历整个 App。”

“开始探索并学习”仅在配置有效、授权勾选、来源可确认且无提交中请求时可用。点击后立即锁定表单、展示校验中；不再增加重复确认弹窗。关闭未提交配置只丢弃本地表单，不调用任务开始。

## 四、状态与交互矩阵

| 状态 / 用户动作 | 前置条件 | 状态转换与期望输出 | 边界行为 |
| --- | --- | --- | --- |
| 未启动 / 开始 | 配置有效、明确授权 | 启动校验中；展示本次目标和预算，停止按钮可用 | 提交无回执时显示“正在确认是否创建”，先查结果，不能直接重复创建 |
| 启动校验通过 | 同设备/App、认证与安全检查可用 | 运行中；展示当前阶段：观察、探索或学习 | 不额外要求用户输入与当前可用模型无关的凭证 |
| 启动校验失败 | 设备忙、App 无效、认证失败等 | 已中断，显示脱敏原因和可执行指引 | 保留已创建任务身份及已知用量；未创建时回到表单，明确“未启动” |
| 运行中 / 暂停 | 当前任务可控 | 暂停处理中；立即显示“不再派发新操作，正在收敛在途请求” | 暂停按钮禁用，停止仍可请求；不能抢先显示已暂停 |
| 暂停完成 | 在途任务已收敛、资源释放 | 已暂停；显示暂停原因、继续和停止 | 时间停止增长；迟到用量仍可补记并标明更新时间，不清零 |
| 已暂停 / 继续 | 同一任务剩余额度有效 | 恢复校验中；检查同设备、App、当前画面及计量 | 不编辑预算、不复制旧坐标、不抢占设备；失败仍暂停并说明原因 |
| 恢复校验通过 | 目标和安全环境一致 | 运行中；累计数接续，继续学习未完成页面 | 无剩余额度则转已结束，并标预算用尽 |
| 活动状态 / 停止 | 启动校验中、运行、暂停、恢复校验或可停止中断 | 先打开停止确认；确认后停止处理中 | 取消确认返回原状态；确认前任务可能仍在执行，提示此点 |
| 停止完成 | 结果已失效、清理完成 | 已停止；保留报告和缓存，展示“新建任务” | 绝不显示继续按钮；新建必须重新配置和授权 |
| 任一预算耗尽 | 包含运行与补记用量达到限制 | 停止派发，清理后已结束，原因“时长/步数/Token 预算用尽” | 不出现“全部页面学习完成”；暂停时补记超额也不可继续 |
| 无安全分支可探索 | 已完成有限尝试 | 已结束，原因“暂无可继续的安全分支” | 未学失败项仍可查看，不以结束替代学习成功 |
| 设备断连或后台退出 | 无法继续执行 | 已中断；最后确认时间、累计数、可恢复性及原因 | 不自动重新启动；可恢复才显示继续，不可恢复只显示停止/新建 |
| 刷新或重新打开网页 | 可能存在任务 | 读取本地任务并恢复面板展示 | 不发送开始或继续请求；配置尚未提交的授权不恢复勾选 |

停止确认文案：“停止后本任务不能继续。已学习缓存和累计报告会保留。如需暂时离开，请选择暂停。”按钮“返回任务”“确认停止”，默认焦点落在返回任务。停止不撤销已经发生的手机动作。

## 五、异步、重复操作与异常反馈

- 每个任务控制操作提交后只允许一个待确认意图；重复点击不重复调度。同一任务多标签页操作以服务端最新状态为准，冲突时读取状态并提示“任务状态已变化”。停止优先于继续，停止处理中不可恢复。
- 控制请求超时不等于失败，更不等于停止成功。显示“控制结果待确认”，持续读取；停止按钮可用时可重发同一停止意图，不另开执行器。
- 状态查询失败保留最后数据，加“状态未确认 · 最后更新时间”；不伪造为仍在正常运行或已暂停。恢复连接只读取状态，不自动继续。
- 学习单页失败展示原因和有限重试进度；不弹阻塞整个页面的重复通知。用量缺失显示“已暂停：用量不可确认”，已知量与未结算请求分开展示，不能显示零或虚构剩余额度。
- 遇到登录、权限、支付、外部 App 或画面不可观察时暂停；展示“请在设备上自行处理，再回到目标 App 后继续”。不提供自动确认、登录、授权或跳过安全检查按钮。恢复仍需重新检查环境。
- 身份环境变化且无法确认安全一致时继续保持暂停，不能仅因包名相同自动放行；不采集个人账号字段用于界面展示。
- 缓存关闭时保留任务与报告入口，禁用新建并说明原因；已运行任务发现缓存能力不可用时暂停，不继续消耗预算做无效学习。
- 当前页预热与探索共用同一设备时受忙碌状态约束，提示先暂停探索。暂停释放设备后其他任务可以使用；继续不能抢占。
- 配置/登录问题链接到已有配置或诊断入口；错误只提供脱敏原因、任务标识和本地诊断指引，不展示认证令牌、原始模型响应或个人页面内容。

## 六、进度、报告与统计文案

任务面板始终展示目标 App 与包名、设备、任务标识、开始时间、状态/原因、最后更新时间及“关闭网页不会停止任务”。运行态提供暂停、停止；暂停态提供继续、停止；终态只提供报告和新建。

三项预算各显示“累计 / 上限”、剩余量及文本单位。预算条仅表达额度消耗，不标为 App 覆盖率。有效时长排除暂停、排队、恢复校验；暂停期间不播放仍在计时的动画。Token 显示探索、学习、辅助分项和已知总量，未知项用“待结算/不可确认”，不用零代替。

逐页结果按任务内页面身份去重：名称 → Activity → 包名加短指纹作为展示兜底，未识别名称显示“名称未识别”，不显示孤立的 unknown page。标题改变不直接建立新身份；指纹可展开查看。

| 指标 | 显示口径 |
| --- | --- |
| 已发现页面 | 实际观察到的目标 App 页面身份数；不表示总页面数 |
| 本次学习成功 | 本任务成功补学的页面数，重复学习同页不重复计页 |
| 已有缓存跳过 | 已有可信完整缓存而无需整页学习的页面数 |
| 不稳定跳过 / 学习失败 / 待重试 | 展示当前结果及原因；可标注历史重试次数，明确可能是同一页不同阶段 |
| 安全拦截 | 被禁止的动作事件数，单位“次”；不能与页面数相加 |

页面表列：展示名、Activity/短指纹、学习状态、原因、尝试次数、最近时间；按状态筛选和分页。学习状态至少含待学习、学习中、已学习、已有缓存、不稳定跳过、失败待重试、失败结束。报告保留最终结果及失败历史；不把互相重叠的事件指标画成总和为 100% 的饼图。

“复访查询命中率”继续使用学习后真实目标查询，展示分子/分母；未发生查询显示“暂无复访查询”，不显示 100%。学习成功和写入控件数独立展示，不计为命中。

## 七、视觉、适配与可访问性

| 项目 | 设计约束 |
| --- | --- |
| 容器与间距 | 沿用页面最大宽 1160px；宽屏页边距 32px，窄屏 16px；面板间距约 20px，内部沿用 24px / 窄屏 18px |
| 颜色与轮廓 | 白色面板，正文沿用 `#182638`；蓝色主操作沿用现有按钮；警告/错误沿用 notice 样式；边框 `#e1e7f0`，面板圆角 18px，轻阴影沿用现有值 |
| 字体与图标 | 继承当前网页字体；面板标题 16px、正文 13–14px、辅助说明 12px；使用现有 Material Symbols，无新图片资源；新增辅助文字保证可读对比度 |
| 表单与卡片 | 随容器 flex 换行，`min-width: 0`；长包名、模型名、数值允许折行；指标参考已有 17rem 基准卡片，不按第几个卡片跨列 |
| 窄屏 | 表单和预算卡自动单列，按钮可换行；仅表格自身横向滚动，页面不整体横溢；停止入口保持可达，不固定遮住内容 |
| 状态差异 | 加载带文字；禁用同时解释原因；错误用文字和图标，不只靠红色；终态停止计时动效 |
| 键盘与读屏 | label 关联字段，Tab 顺序按视觉阅读顺序，焦点清晰；状态摘要 aria-live polite，字段错误关联说明；关键错误使用 alert，普通数值刷新不反复播报 |
| 确认与焦点 | 停止确认支持键盘取消并归还触发按钮焦点；折叠面板不丢失任务；不设置危险的全局开始/停止快捷键 |

比较标准：先对照当前缓存页的视觉体系，再核对本文新增状态、文案、布局和控制可达性。验收覆盖桌面 1280px、平板 780px、手机 390px，并增加窄容器 240/320px 及浏览器 200% 缩放，检查长文本与大量数字。尺寸是验证样本，布局必须按可用容器宽度工作。

相关 UI 在任务拆分时标记为设计还原检查候选；严格检查仅在用户后续明确选择后启用。当前没有自动截图对比要求，截图与人工对照即可，不额外引入截图工具链作为门禁。

## 八、验收路径与证据清单

以下是未来验收要求，本轮不编写设备测试或运行模型。编写手机交互测试前按项目规则先用 ARTEMIS 探索；真实设备验证另需确定设备、App、预算及截图授权。

| 路径 | 期望及证据 |
| --- | --- |
| 空态→配置→校验→运行 | 配置空态截图、必填与越界错误、来源及授权展示；实际任务状态证据，无重复任务 |
| 运行→暂停处理→暂停→继续 | 三状态截图及调度记录；暂停完成无新动作/学习，恢复先读取新画面，累计数不重置 |
| 运行/暂停→停止确认→停止 | 确认/取消截图与终态截图；资源释放后显示停止，刷新及多标签页都无继续入口 |
| 分别耗尽三种预算 | 每种结束原因与累计数证据；无新调度，不宣称覆盖完成；Token 结算延迟提示可见 |
| 重访、名称变化、XML 页面 | 页面结果列表及真实缓存查询证据；去重合理，名称有兜底，直接定位不漏学习检查 |
| 敏感动作、外部窗口及未知语义 | 派发前阻止证据；暂停原因截图，无点击敏感操作或绕过按钮 |
| 断连、用量缺失、查询超时、后台退出 | 保留已知量和最后更新时间，不自动恢复、不显示假零；可恢复性和手动操作可见 |
| 长文本与各尺寸 | 配置、运行、暂停、终态在三类宽度截图；窄容器和缩放无遮挡，无整页横溢 |
| 回归 | 原有预热、累计缓存效果、明细及统计刷新正常；学习写入不伪造复访命中 |

AI 后续可验证状态转换、幂等、字段校验、调度约束及布局尺寸；页面可读性、确认文案理解和实际安全探索体验须结合运行截图、设备证据与人工评审，不能仅凭组件单测标为通过。
