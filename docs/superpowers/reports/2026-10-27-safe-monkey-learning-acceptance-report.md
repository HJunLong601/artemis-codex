# 安全 Monkey 探索与页面学习验证记录

日期：2026-10-27。按已确认的安全探索规格实现；用户授权自行完成后续方案和实现。最新“不限制”补充规格优先于早期必须填写三项预算的描述。

## 交付结果

后台 `/cache` 新增独立的安全探索任务入口，明确选择单个 Android 设备和 App。时长必填且有限，最大操作步数和 Token 默认“不限制”，也可分别设置有限上限。API 使用 `null` 表示不限制；0 不表示不限制。

任务由后台独立进程执行，任务、页面结果和累计预算持久化到本地。暂停后可继续，时长、步数和用量不清零；停止是终态。页面学习检查不依赖页面展示名称，完整缓存跳过重复付费学习。未确认的用量保留为未结算，不能按零处理。

操作仅开放有证据的导航、受限滑动和返回。危险语义、敏感窗口、离开目标 App、无法观察或返回落点异常时拒绝执行或暂停。关闭浏览器不停止任务，后台重启不自动恢复执行。

使用方法见 [功能说明](../../cache-exploration.md)，最新预算规则见 [补充规格](../specs/2026-10-27-safe-monkey-learning-unlimited-amendment.md)。

## 实际推理和真机验证

先通过 ARTEMIS 环境诊断和真机页面观察，再编写交互相关测试。仅使用单台已授权 Android 真机，模型输入使用无个人数据的测试 App；任务账本和缓存使用隔离的本地临时目录。

| 场景 | 实际结果 |
| --- | --- |
| 模型认证及推理 | 合成图片请求成功返回结构化结果，取得完整用量 16397 Token |
| 有限预算探索 | 3 个操作，已知用量 170832 Token；剩余额度不足以准入下一次请求后结束 |
| 页面学习 | 四个稳定页面状态、37 个位置；包含夹具布局调整前后不同指纹，未将它们误当成同一状态 |
| 请求中暂停 | 当前请求结算后暂停：累计 1 步、94940 Token，未结算数为 0；继续后累计值保留 |
| 缓存复用 | 对当前页面三个实际目标查询获得 3/3 命中；新任务首屏跳过已有完整学习，没有把写入计作命中 |
| 停止 | 停止后无任务进程；继续请求返回 409 |
| 实际模型中断 | 收到远端中断确认，任务停止；无法取得最终用量的调用保留为未结算，没有记成零消费 |
| 仅限制时长 | 1 分钟任务，两项上限均为 null；累计 8 步、已知 150231 Token，最终因时长预算结束 |

仅限制时长的同一任务曾因夹具自定义 Back 落点不符合已观察路径而安全暂停，人工继续后仍保留累计预算，约 59.2 秒有效时长结束。短时间片预留使结束略早于上限；结束时一个在途调用的最终用量未知，报告明确保留未结算状态。

ARTEMIS 在探索和暂停后检查测试 App，危险操作计数均为 0。初次发现夹具标题与系统状态栏重叠后修正的是夹具窗口内边距，没有放宽生产代码的页面变化保护。后台重启后终态报告保留，没有自动重跑。
